01 / OVERVIEW

What is GitHub Actions?

GitHub Actions is a CI/CD automation platform integrated directly into GitHub. It allows developers to execute automated tasks whenever events occur in a repository.

↻

Automated CI

Build and test application code whenever developers push changes.

⬆

Automated Delivery

Build container images and publish them to container registries.

✓

Reliable Workflows

Standardize repetitive engineering tasks with reusable automation.

02 / CORE CONCEPTS

Understanding a workflow

A workflow is an automated process defined in a YAML file inside the .github/workflows directory.

01

Event

Defines what triggers the workflow, such as push or pull_request.

02

Workflow

The complete automated process defined in a YAML file.

03

Jobs

Groups of tasks that execute on a runner. Jobs can depend on other jobs.

04

Runner

The machine that executes workflow jobs.

05

Steps

Individual commands or actions executed inside a job.

03 / EXECUTION ENVIRONMENT

GitHub Runners

Runners provide the compute environment required to execute workflow jobs.

MANAGED

GitHub-hosted Runner

Infrastructure managed by GitHub.

  • No server maintenance
  • Preconfigured environments
  • Fresh runner for each job
SELF-MANAGED

Self-hosted Runner

Infrastructure managed by your organization.

  • Control over the environment
  • Access to private infrastructure
  • Custom hardware and software
04 / SECURITY

Secrets & Variables

Store configuration and sensitive credentials securely instead of hardcoding them into workflow files.

⌑

Repository Secrets

For sensitive values such as access tokens and passwords.

⚙

Repository Variables

For non-sensitive configuration such as usernames and environment names.

06 / DOCKER AUTOMATION

Build and push Docker images

GitHub Actions can automate Docker image creation and publishing to Docker Hub or other container registries.

docker-build-push.yml 
name: Build and Push Docker Image

on:
  push:
    branches:
      - main

jobs:
  docker:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Code
        uses: actions/checkout@v6

      - name: Login to Docker Hub
        uses: docker/login-action@v4
        with:
          username: ${{ vars.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}

      - name: Setup Buildx
        uses: docker/setup-buildx-action@v4

      - name: Build and Push
        uses: docker/build-push-action@v7
        with:
          context: .
          push: true
          tags: ${{ vars.DOCKERHUB_USERNAME }}/github-actions-demo:latest
Engineering note

Credentials are stored in GitHub repository settings. Never commit access tokens or passwords to source control.
